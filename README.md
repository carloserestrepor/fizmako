FIZMAKO
Sovereign Technology Ecosystem for Community Resilience in the Colombian Andes
Fizmako is a modular, offline edge AI and communication architecture designed for rural Andean communities in Colombia lacking functional connectivity. It integrates a local mesh network, edge computing units running 1.58-bit quantized models (ternary architecture), low-cost agroecological sensors, and a community visual interface (HUB75 Modular Wall).
All data is processed locally without corporate servers or cellular dependency, ensuring data sovereignty and community agency.
Alignment with Human-Scale AI Principles

    Small: Uses 1.58-bit ternary quantization on low-power commodity hardware (Raspberry Pi 5), reducing energy and memory use by 16x.
    Intentional: The community owns, configures, and prunes local knowledge. Data never leaves the node.
    Tailored: Designed alongside native seed custodians for specific Andean microclimates and languages.
